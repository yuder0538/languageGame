# 聽力練習選擇題遊戲

這是一個簡單的語言聽力練習網頁，目前提供德文與日文兩個語言練習模式。使用者可以先從語言選單中選擇想挑戰的語言，再按「播放句子」聽句子並選出最符合的中文翻譯。

## 功能

- 生活化德文與日文句子
- 使用瀏覽器語音合成（SpeechSynthesis）播放語音
- 中文選擇題回答
- 答對 / 答錯提示
- 每次按下一題或重新開啟頁面時，題目會隨機抽取且不重複
- 首頁語言選單，可選擇德文或日文

## 使用方式

1. 直接在瀏覽器中打開 `index.html`
2. 選擇「德文聽力練習」或「日文聽力練習」
3. 按「播放句子」聆聽句子
4. 選擇最接近的中文意思
5. 按「下一題」切換下一個句子

## 注意事項

- 建議使用支援語音合成的瀏覽器，例如 Chrome、Edge
- 若語音無法播放，可確認瀏覽器是否允許自動播放音訊
- 若直接從 GitHub 倉庫頁面開啟，請確保點選 `index.html` 進入選單

## 檔案

- `index.html`：語言選單入口
- `german-listen-quiz.html`：德文練習頁面
- `japanese-listen-quiz.html`：日文練習頁面
- `README.md`：使用說明文件

# 德文聽力練習選擇題

這是一個簡單的德文聽力練習網頁，使用者可以按下「播放句子」，聽德語句子後選出最符合的中文翻譯。

## 功能

- 生活化德文句子
- 使用瀏覽器語音合成（SpeechSynthesis）播放德文
- 中文選擇題回答
- 答對 / 答錯提示
- 題目不重複，適合初學者練習

## 使用方式

1. 直接在瀏覽器中打開 `german-listen-quiz.html`
2. 按「播放句子」聆聽德語
3. 選擇最接近的中文意思
4. 按「下一題」切換下一個句子

## 注意事項

- 建議使用支援語音合成的瀏覽器，例如 Chrome、Edge
- 若語音無法播放，可確認瀏覽器是否允許自動播放音訊
